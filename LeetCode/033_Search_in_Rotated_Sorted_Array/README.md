# 33. Search in Rotated Sorted Array

## Problem Information

- **Platform:** LeetCode
- **Problem Number:** 33
- **Difficulty:** Medium
- **Language:** C++
- **Topics:** Array, Binary Search

## Problem Link

https://leetcode.com/problems/search-in-rotated-sorted-array/

## Approach

Use Binary Search to identify the sorted half of the rotated array and determine where the target lies. This ensures an efficient search with logarithmic time complexity.

## Complexity

- **Time Complexity:** O(log n)
- **Space Complexity:** O(1)
